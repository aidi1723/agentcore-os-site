使用说明与阅读路径

首页已经包含大量定位信息，但如果用户第一次接触 AgentCore OS，容易停在“理念很强、到底怎么用”这一层。所以这页把首页内容拆成更容易行动的阅读路径。

如果你是创客 / 独立开发者

  • 先看首页的 Use Cases，确认它想解决的是不是你自己的自动化问题。
  • 再看 Architecture，理解本地优先、审批边界和资产沉淀这些核心主张。
  • 最后回到 GitHub 仓库，评估是否值得 fork 成你自己的品牌页或产品入口。

如果你是业务负责人

  • 重点看首页里的“不是聊天，而是让 AI 进入真实业务流”这一主线。
  • 关注 Human-in-the-loop 审批、本地存储、边界可控这几个关键词。
  • 把它理解成一个生产力底座，而不是一个单点聊天工具。

如果你是集成者 / 技术合作方

  • 先确认许可证与仓库公开范围。
  • 再看首页的架构与开发者定位，判断未来如何嵌入自己的自动化系统或产品矩阵。
  • 如果后续要扩展，这个站点本身也适合作为文档门户继续长出来。
