Getting Started

如何开始使用 AgentCore OS

当前公开站点是一个官网落地页，不是完整安装包分发页。所以“如何开始”最合理的路径，是先理解公开内容、查看仓库与许可证，再通过静态方式预览当前网站，并据此决定后续接入或扩展方向。

第一步：先看公开内容和仓库结构

先进入 GitHub 仓库，确认你当前拿到的到底是什么：官网源码、README、静态资源，以及 GitHub Pages 部署方式。

GitHub 仓库 查看源码、目录结构、提交记录与后续演进。 README 当前仓库的简要说明、技术栈与本地预览方式。

第二步：看清许可证与可用边界

如果你要 fork、改版、接入商业项目，先看许可证最稳。当前项目页面与文案都强调 Apache 2.0，因此建议把这一点作为对外沟通的基础信息之一。

Apache 2.0 许可证 确认修改、分发、商业集成和保留声明等基本边界。

第三步：预览当前公开版本

这个仓库当前是纯静态站点，最简单的预览方式有两种：

  • 直接打开仓库中的 index.html。
  • 访问 GitHub Pages 线上地址，看部署后的真实落地页效果。
线上预览地址 查看当前 GitHub Pages 发布版本。 index.html 直接查看当前首页源码与文案结构。
