Getting Started

如何开始使用 AgentCore OS

当前公开站点已经不只是概念页：它有官网、文档中心和国内源码仓库，但不再保留 ECS 的 Mac / Windows 直链下载。因此“如何开始”的最佳路径，是先看清公开边界，再进入仓库、文档和线上预览，而不是先找安装包。

第一步：先看公开内容和仓库结构

先进入国内仓库，确认你当前拿到的是什么：官网源码、README、docs 页面，以及当前对外公开的体验与使用说明。

国内仓库 查看源码、目录结构、提交记录与后续演进。 README 查看当前公开版本说明、技术边界与主要入口。

第二步：看清文档与公开边界

如果你想判断它能不能直接拿来用，先看 docs 和公开发布说明最稳。现在的重点不是承诺完整私有能力，而是把当前公开版本的边界讲清楚。

Docs 文档中心 统一查看快速开始、使用说明、安装部署、工作流与 FAQ。 开发者与许可证入口 回到首页开发者区，查看 Apache 2.0 与对外协作定位。

第三步：预览并按文档开始体验

现在最简单的体验方式有三种：

  • 访问 ECS 线上站点，看当前真实落地页与文档入口。
  • 从首页和文档中心进入国内源码仓库，按 README 与中文文档自行体验。
  • 在 docs 内继续阅读安装部署、工作流和 FAQ，再决定是否继续接入、二次开发或对外分发。
线上预览地址 查看当前 ECS 线上站点发布版本。 源码与说明入口 从首页进入国内源码仓库与中文文档，不再使用 ECS 安装包直链。
