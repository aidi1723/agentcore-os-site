Install & Deploy

安装与部署

当前仓库公开的是 AgentCore OS 的官网静态站点，而不是完整桌面应用安装器。因此这里的“安装与部署”，重点是如何预览、如何托管、以及后续如果站点升级成更完整产品文档时该怎么扩展。

1. 本地预览

方式 A：直接打开 HTML

当前站点是纯静态页面，最简单的方式就是直接打开仓库中的 index.html。这适合快速看页面结构、文案和视觉效果。

方式 B：用静态文件服务启动

如果你希望更接近线上访问方式，可以在仓库目录下启动一个本地静态服务：

cd agentcore-os-site
python3 -m http.server 8000

然后在浏览器里打开：

http://localhost:8000

为什么这里不需要额外安装依赖

  • 当前仓库没有复杂前端构建链要求。
  • 页面由静态 HTML / CSS / JS 构成。
  • 所以你不需要先装 Node 依赖，直接预览即可。

2. 线上站点部署

线上地址

当前 ECS 站点预览地址是：

http://59.110.93.188

发布方式

当前这套国内版页面由 ECS 上的静态站点直接提供。你改完 index.html 或 docs/ 后，只需要同步到服务器并让 nginx 继续提供即可。

适合当前阶段的发布策略

  • 轻文案调整：直接改 index.html 和 docs/ 下的页面。
  • 结构扩展：继续在 docs/ 目录新增文档页。
  • 保持简单：在真正需要框架前，不急着引入 Astro / Next / Vite。

3. 后续扩展建议

什么时候需要升级站点结构

  • 当文档页数量明显增多。
  • 当你需要统一导航、搜索、版本管理或多语言切换。
  • 当官网不再只是 landing page，而是产品门户 + 文档中心。

建议优先补的内容

FAQ 快速回答“它是什么、适合谁、当前能做什么”。 使用说明与阅读路径 给第一次进入站点的人一个不迷路的阅读顺序。 快速开始 用最短路径把用户带到真实入口，而不是停在口号里。
