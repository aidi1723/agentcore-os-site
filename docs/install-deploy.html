安装与部署

当前公开的不只是官网源码，也包含真实下载入口与文档页。因此这里的“安装与部署”分成两件事：一是用户如何获取公开版本，二是站点维护者如何本地预览并同步 ECS 线上页面。

1. 用户安装入口

Mac 安装包

当前公开的 Mac 安装包已经放在官网下载区，适用于 Apple Silicon（aarch64）。

Windows 安装包

Windows x64 安装包也已经公开上线，首页下载区提供正式链接，并保留旧文件名兼容别名。

为什么这里还要保留 docs

  • 下载入口解决“拿到什么”。
  • docs 页面解决“它是什么、适合谁、怎么理解”。
  • 两者一起，才构成完整的公开版本体验。

2. 站点本地预览

方式 A：直接打开 HTML

当前站点是纯静态页面，最简单的方式就是直接打开仓库中的 index.html 和 docs/*.html。

方式 B：启动静态文件服务

如果你希望更接近线上访问方式，可以在仓库目录下启动本地静态服务：

cd agentcore-os-site-ecs-cn
python3 -m http.server 8000

然后在浏览器里打开 http://localhost:8000。

为什么这里不需要额外依赖

  • 当前仓库没有复杂前端构建链。
  • 页面由静态 HTML / CSS / JS 构成。
  • 所以不用先装 Node 依赖，直接预览即可。

3. ECS 发布与后续扩展

线上地址

当前 ECS 站点地址是：

http://59.110.93.188

发布方式

当前国内版页面由 ECS 上的静态站点直接提供。改完 index.html 或 docs/ 后，只需要同步到服务器并继续由 nginx 提供即可。

什么时候该升级站点结构

  • 当文档页数量继续明显增长。
  • 当你需要统一导航、搜索、版本管理或多语言体系。
  • 当官网不再只是 landing page，而是产品门户 + 文档中心。

这一页讲的是当前公开站点如何预览和发布，不等于完整桌面产品的全部构建与交付流程都已经在这个仓库里公开。
