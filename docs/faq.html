FAQ

把首页里最容易让人误会、但又最常问的问题先说清楚。这样用户不会看完一圈还停在“听起来很强，但到底是什么”。

1. AgentCore OS 到底是什么？

从当前官网表达看，它被定义为一个 本地优先的 AI 生产力底座 / AI 操作系统，核心不是“聊天”，而是让 AI 进入真实业务流、自动化流和审批流。

2. 它是一个聊天工具吗？

不是首页想强调的重点。首页反复强调的主线是：它不是又一个聊天客户端，而是一个能够承接工作流、资产、审批和本地执行边界的系统。

3. 当前这个 GitHub 仓库公开了什么？

当前 aidi1723/agentcore-os-site 仓库公开的是官网静态站点本身，也就是 landing page 和 docs 页面的源码，不等于完整桌面产品安装包仓库。

4. 那我现在能怎么用它？

  • 先通过官网理解产品定位。
  • 通过 GitHub 仓库查看公开内容。
  • 通过 README、快速开始、安装部署页看清当前可预览范围。
  • 如果你是品牌方或集成方，也可以先把这个站点当作对外入口继续完善。

5. 当前站点适合谁？

  • 创客 / 独立开发者：看是否值得 fork 或延展成自己的产品页。
  • 业务负责人：判断它的本地优先、审批边界是否适合团队工作流。
  • 集成者：评估协议、定位和架构表达是否适合作为未来集成入口。

6. 为什么首页之前会让人觉得“按钮打不开”？

因为那一版更像解释性内容，而不是文档导航。现在已经补上了真实可点击入口，包括快速开始、使用说明、安装与部署、FAQ 等页面。
