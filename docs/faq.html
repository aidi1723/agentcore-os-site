常见问题

把首页里最容易让人误会、但又最常问的问题先说清楚。这样用户不会看完一圈还停在“听起来很强，但到底是什么”。

1. AgentCore OS 到底是什么？

从当前官网表达看，它被定义为一个 本地优先的 AI 生产力底座 / AI 操作系统，核心不是“聊天”，而是让 AI 进入真实业务流、自动化流和审批流。

2. 它是一个聊天工具吗？

不是首页想强调的重点。首页反复强调的主线是：它不是又一个聊天客户端，而是一个能够承接工作流、资产、审批和本地执行边界的系统。

3. 当前这个国内仓库公开了什么？

当前公开仓库包含官网静态站点本身，也就是 landing page、下载入口与 docs 页面源码；它不等于完整桌面产品的全部私有仓库与内部能力。

4. 那我现在能怎么用它？

  • 先通过官网理解产品定位。
  • 通过国内仓库查看公开内容。
  • 通过 README、快速开始、安装部署页看清当前可预览与可下载范围。
  • 如果你是品牌方或集成方，也可以先把这个站点当作对外入口继续完善。

5. 当前站点适合谁？

  • 创客 / 独立开发者：看是否值得 fork 或延展成自己的产品页。
  • 业务负责人：判断它的本地优先、审批边界是否适合团队工作流。
  • 集成者：评估协议、定位和架构表达是否适合作为未来集成入口。

6. 为什么之前会让人觉得“按钮打不开”或“英文不完整”？

因为网站早期更像解释性内容，而不是一套完整的导航型公开站点。现在已经逐步补上了真实下载、docs 子页和中英切换逻辑，但还需要持续做整站级校对。

7. 现在要从哪里开始？

  • 快速开始
  • 安装与部署
  • 使用说明与阅读路径
  • 国内仓库

如果后续补齐更完整的产品仓库、安装器说明或 API 文档，这个 FAQ 也应该同步更新，避免官网承诺超前于公开内容。
